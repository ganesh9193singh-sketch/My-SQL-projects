# My-SQL-projects

MySQL practice projects arranged in a clear beginner-to-project sequence.

## 📁 Project Structure

| Step | File / Folder | Description |
|---|---|---|
| 01 | `01_basic_sql/01_basic_queries/Basic-Queries.sql` | Basic MySQL queries: SELECT, WHERE, ORDER BY, GROUP BY, HAVING and JOIN |
| 02 | `01_basic_sql/02_data_cleaning/Data-Cleaning.sql` | Data cleaning: duplicates, NULL values, TRIM, LOWER and date handling |
| 03 | `01_basic_sql/03_problem_solving/Problem_Solving.sql` | SQL problem-solving practice |
| 04 | `01_basic_sql/04_mini_project/Sales_Analysis.sql` | Mini sales analysis project |

## 🧠 Learning Path

1. **Basic Queries** — learn the main SQL commands.
2. **Data Cleaning** — clean and prepare data for analysis.
3. **Problem Solving** — apply SQL to practical questions.
4. **Mini Project** — use SQL for a complete sales analysis.

## 🛠️ Topics Covered

- SELECT, WHERE and ORDER BY
- GROUP BY and HAVING
- JOIN and LEFT JOIN
- COUNT, SUM, AVG and MAX
- Data cleaning
- Duplicate and NULL handling
- Date formatting
- Sales analysis

## 🚀 How to Run

1. Install MySQL Server and MySQL Workbench.
2. Open the SQL file for the step you want to practice.
3. Run the queries in MySQL Workbench.
