# My-SQL-projects

MySQL practice projects covering basic queries, data cleaning, problem solving, and a mini sales analysis project.

## 📁 Project Structure

| Path | Description |
|---|---|
| `01_basic_sql/Basic-Queries.sql` | Basic MySQL queries (SELECT, WHERE, GROUP BY, JOIN) |
| `01_basic_sql/02_data_cleaning/Data-Cleaning.sql` | Cleaning messy data (duplicates, NULL, trim, emails) |
| `01_basic_sql/03_problem_solving/Problem_Solving.sql` | 8 SQL problem solving queries |
| `01_basic_sql/04_mini_project/sales_analysis.sql` | Mini sales analysis project |

## 🧠 Topics Covered

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- JOIN and LEFT JOIN
- Aggregate functions (COUNT, SUM, AVG, MAX)
- Data cleaning (TRIM, LOWER, NULLIF, STR_TO_DATE)
- Removing duplicate records
- Handling NULL values
- Date formatting (DATE_FORMAT)

## 🚀 How to Run

1. Install MySQL Server and MySQL Workbench
2. Open any `.sql` file from this repository
3. Run the script in MySQL Workbench

## 🎯 Learning Path

1. Start with `Basic-Queries.sql`
2. Then `02_data_cleaning/Data-Cleaning.sql`
3. Then `03_problem_solving/Problem_Solving.sql`
4. Finish with `04_mini_project/sales_analysis.sql`
