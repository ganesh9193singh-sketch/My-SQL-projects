# MySQL Mini Project - Sales Analysis

This folder contains a small MySQL sales analysis project.

## Analysis Included

- Total customers
- Total orders
- Total sales
- Average order amount
- Monthly sales
- Top customers by spending
- Customers with no orders
- City-wise sales

## Tables Used

- customers
- orders

## Concepts Used

- JOIN
- LEFT JOIN
- GROUP BY
- DATE_FORMAT
- Aggregate functions (COUNT, SUM, AVG)
